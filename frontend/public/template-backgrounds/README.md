# Template backgrounds

## Naming (per template folder)

- `background.webp`: the main background image (required)
- `background-mobile.webp`: smaller version for narrow screens (optional)
- `thumb.webp`: tiny blurred placeholder, ~32px wide, used for instant loading (optional)

## Image specs

- Format: WebP preferred (JPG/PNG accepted, I'll convert later)
- Size: 1920×1080 minimum, 16:9 landscape; mobile version 900×1600 portrait
- File size: under 300 KB for desktop, under 150 KB for mobile
- Composition: keep the center of the image calmer and less busy, since the process nodes sit there; put the visual detail toward the edges
- Avoid: text, logos, watermarks, and people's faces in sharp focus at the center
- Style: consistent lighting and color mood across all five so the app feels cohesive

## Notes

- Originals (full resolution) should be kept outside this folder, since these are optimized copies for the app
- Blank project intentionally has no background
